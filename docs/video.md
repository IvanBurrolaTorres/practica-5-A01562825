# Guion del video solicitado — 60 segundos

**Este archivo es un guion. No hay un video grabado ni capturas de ejecución.**

Grabar la aplicación real y Android Studio con Database Inspector, no un prototipo.

| Tiempo aproximado | Acción que debe quedar visible |
|---|---|
| 0–16 s | Agregar un producto con cantidad mayor que uno y mostrarlo en la lista. |
| 16–28 s | Terminar la aplicación, volver a abrirla y mostrar que el producto sigue ahí. |
| 28–39 s | Entrar al detalle y vender una unidad. Mostrar la cantidad actualizada. |
| 39–50 s | Mostrar `inventario.db` y la tabla `productos` en Database Inspector. |
| 50–60 s | Borrar el producto y mostrar la lista actualizada y, si está visible, la fila eliminada. |

Ruta del inspector indicada en la guía: View → Tool Windows → App Inspection → Database Inspector. Seleccionar `mx.tec.inventario` y activar Live updates.

La entrega pide además un repositorio privado con acceso al profesor y una defensa oral. Un ZIP o este guion no los reemplazan.
